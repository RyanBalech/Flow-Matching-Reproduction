# Reproduction protocol

## Target

Reproduce the central conditional-flow-matching mechanism from Lipman et al. (ICLR 2023) with an independent PyTorch implementation.

The first phase deliberately uses 2-D distributions. This makes vector fields, trajectories and failure modes directly inspectable before scaling compute.

## Phase 1 — correctness

- Verify path endpoint and velocity identities analytically and with unit tests.
- Verify numerical ODE solvers against vector fields with known solutions.
- Fit a time-conditioned MLP on eight-Gaussians and checkerboard targets.
- Save seeds, hyperparameters, package versions and metrics.

## Phase 2 — reproduction / ablation

Compare path choices under matched:
- optimizer and learning-rate schedule,
- number of training examples / updates,
- architecture and parameter count,
- random seeds,
- sampling budget.

Report sample-quality metrics with mean and uncertainty across seeds.

## Phase 3 — numerical efficiency

Compare Euler and RK4 as a function of number of function evaluations (NFE), rather than merely number of solver steps. This avoids giving higher-order solvers an unreported compute advantage.

## Leakage / reporting rule

No manual selection of favorable seeds. Failed runs remain in the experiment record. The README receives quantitative claims only after metrics are generated by committed experiment code.
